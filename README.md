
# Amazon Sales & Operations Performance Dashboard

## Project Overview
This project provides an end-to-end analysis of Amazon Sales & Operations performance using interactive dashboards.

## Key Metrics
- **Total Revenue:** 4.11M
- **Total Orders:** 7K
- **Average Order Value (AOV):** 580.40
- **Return Rate %:** 1.92%

## Key Insights
1. **Top States:** Maharashtra and Karnataka drive the highest revenue.
2. **B2B vs B2C:** B2C orders dominate overall sales revenue.
3. **Discount Impact:** Analyzed total revenue distribution based on discount application.

## Tools Used
- Power BI / Tableau / Excel
- Dataset: Amazon Sales Data
